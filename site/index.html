darts-o-mat

A free, open-source darts scorer that you host yourself. Enter your throws or let cameras detect them – the score is counted for you.

Get startedView on GitHub
Early development

Features

Self-hosted

One program or one container, with SQLite for the living room or PostgreSQL for more. Your games and data stay with you.

Free & open source

Licensed under the AGPL-3.0. No subscription, no account at somebody else’s service.

Auto-scoring

darts-o-cam detects the darts with cheap cameras at the board and enters them into the running game. macOS, Linux and Windows.

Play together

X01 and Around the Clock, legs and sets, knockout and round-robin tournaments, friends, guests and statistics. English and German.

Get started

Server

Download it for your system from the latest release:

  • WindowsIntel/AMD · ARM
  • macOSApple silicon · Intel
  • Linux .debIntel/AMD · ARM
  • Linux .rpmIntel/AMD · ARM
  • Linux .tar.gzIntel/AMD · ARM

On macOS or Linux, one line in the terminal picks the right file, installs it and, run again later, updates it:

curl -fsSL https://raw.githubusercontent.com/sj14/darts-o-mat/main/install.sh | bash -s -- --server

Unpack it and start darts-o-mat (in the Linux .tar.gz it is usr/bin/darts-o-mat). The Linux packages install it as a service instead: sudo systemctl enable --now darts-o-mat. Then open localhost:3000 to register. Played by hand, this is all you need. More about darts-o-mat, e.g. as a container, on Kubernetes or with PostgreSQL.

Camera (optional)

darts-o-cam runs on the computer the cameras are connected to. Download it from the latest release:

  • WindowsIntel/AMD · ARM
  • macOSApple silicon · Intel
  • Linux .debIntel/AMD · ARM
  • Linux .rpmIntel/AMD · ARM
  • Linux .tar.gzIntel/AMD · ARM

Not sure? Most PCs are Intel/AMD, a Raspberry Pi is ARM, and Macs from 2020 on are Apple silicon.

On macOS or Linux, one line in the terminal picks the right package, installs it and, run again later, updates it:

curl -fsSL https://raw.githubusercontent.com/sj14/darts-o-mat/main/install.sh | bash

Add and calibrate the cameras once, then enter the server address and the board’s token in its settings. More about darts-o-cam
