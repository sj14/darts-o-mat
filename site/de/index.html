darts-o-mat

Ein freier Open-Source-Darts-Zähler, den du selbst betreibst. Gib deine Würfe ein oder lass Kameras sie erkennen – die Punkte zählt das Programm.

Features

Selbst gehostet

Ein Programm oder ein Container, mit SQLite fürs Wohnzimmer oder PostgreSQL für mehr. Deine Spiele und Daten bleiben bei dir.

Frei & Open Source

Unter der AGPL-3.0 lizenziert. Kein Abo, kein Konto bei einem fremden Dienst.

Automatisch zählen

darts-o-cam erkennt die Darts mit günstigen Kameras am Board und trägt sie ins laufende Spiel ein. macOS, Linux und Windows.

Zusammen spielen

X01 und Around the Clock, Legs und Sets, K.-o.- und Jeder-gegen-jeden-Turniere, Freunde, Gäste und Statistiken. Deutsch und Englisch.

Loslegen

1. Server starten

Go installieren, dann:

git clone https://github.com/sj14/darts-o-mat
cd darts-o-mat
go run ./cmd/darts-o-mat

localhost:3000 öffnen und registrieren. Wer von Hand spielt, braucht nur das.

Oder als Container

Mit Docker oder Podman, im Projektordner:

docker build -f Containerfile -t darts-o-mat .
docker run -d -p 3000:3000 -v darts-o-mat:/data darts-o-mat

Die Daten liegen im Volume darts-o-mat.

2. Kameras hinzufügen (optional)

Auf dem Rechner, an dem die Kameras hängen:

go run ./cmd/darts-o-cam

Kameras einmal hinzufügen und kalibrieren, dann in den Einstellungen Serveradresse und Token des Boards eintragen. Mehr zu darts-o-cam
