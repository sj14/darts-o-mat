darts-o-mat

Ein freier Open-Source-Darts-Zähler, den du selbst betreibst. Gib deine Würfe ein oder lass Kameras sie erkennen – die Punkte zählt das Programm.

Features

Selbst gehostet

Ein Programm oder ein Container, mit SQLite fürs Wohnzimmer oder PostgreSQL für mehr. Deine Spiele und Daten bleiben bei dir.

Frei & Open Source

Unter der AGPL-3.0 lizenziert. Kein Abo, kein Konto bei einem fremden Dienst.

Automatisch zählen

darts-o-cam erkennt die Darts mit günstigen Kameras am Board und trägt sie ins laufende Spiel ein. macOS, Linux und Windows.

Zusammen spielen

X01 und Around the Clock, Legs und Sets, K.-o.- und Jeder-gegen-jeden-Turniere, Freunde, Gäste und Statistiken. Deutsch und Englisch.

Loslegen

Server

Der Server zählt die Punkte, speichert Accounts, Spiele und Statistiken, und gespielt wird auf seiner Webseite, am Handy, Tablet oder Computer. Ein Server reicht für alle Spieler und Boards; er läuft auf jedem Rechner, der beim Spielen an ist. Betreiben Freunde einen oder nutzt du einen öffentlichen, brauchst du keinen eigenen: Öffne einfach seine Adresse.

Mehr zu darts-o-mat, z. B. als Container, auf Kubernetes oder mit PostgreSQL.

Server herunterladen

Für dein System aus dem neuesten Release laden:

  • WindowsIntel/AMD · ARM
  • macOSApple silicon · Intel
  • Linux .debIntel/AMD · ARM
  • Linux .rpmIntel/AMD · ARM
  • Linux .tar.gzIntel/AMD · ARM

Unter macOS oder Linux sucht eine Zeile im Terminal die passende Datei aus, installiert sie und aktualisiert sie, wenn du sie später noch einmal ausführst:

curl -fsSL https://raw.githubusercontent.com/sj14/darts-o-mat/main/install.sh | bash -s -- --server

Entpacken und darts-o-mat starten (im Linux-.tar.gz liegt es unter usr/bin/darts-o-mat). Die Linux-Pakete installieren es stattdessen als Dienst: sudo systemctl enable --now darts-o-mat. Danach localhost:3000 öffnen, um dich zu registrieren.

Kamera

darts-o-cam brauchst du nur, wenn Kameras am Board die Darts erkennen sollen; ohne gibst du deine Würfe auf der Spielseite ein. Es läuft auf dem Rechner, an dem die Kameras hängen, und schickt die Darts an einen Server: deinen eigenen, den deiner Freunde oder einen öffentlichen.
